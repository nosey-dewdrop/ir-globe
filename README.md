# ir-globe

*a slowly spinning globe that shows how countries are tied to each other — starting with the global arms trade.*

### live: https://damlahelloworld.github.io/ir-globe/

## what is this?
international relations are easier to feel than to read. this globe draws country-to-country ties as glowing arcs, so patterns that hide in spreadsheets become visible in one spin. v1 maps who sells arms to whom; more layers (grain and other ties) are on the way.

## features
- rotating WebGL globe with country-to-country arcs
- arms trade network as the first data layer
- landing page with proper SEO
- weekly newsletter signup (bulten)
- privacy page (KVKK)

## technologies
- vanilla JavaScript + WebGL globe
- static site on GitHub Pages
- curated public datasets in data/

## where this is going
a weekly data pipeline, follow-your-countries personalization, a personal briefing page and a livelier globe (counters, stamps, a small feed). the goal: a place an IR student checks every week without being told to.
